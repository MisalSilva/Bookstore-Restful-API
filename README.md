# 📚 **Bookstore RESTful API**
This project is a RESTful API for managing a bookstore system. It includes core functionalities such as managing books, authors, customers, carts, and orders. The API is built using Java (JAX-RS) and supports data exchange in JSON format. It also includes robust exception handling and is tested using Postman.

### 🚀 **Features**
- 🔍 Book Management – Add, update, view, and delete books.
- ✍️ Author Management – Manage authors associated with books.
- 👤 Customer Management – Register and manage customer information.
- 🛒 Cart System – Add items to a customer's cart and manage them.
- 📦 Order System – Convert cart items into orders and track order status.
- ❌ Exception Handling – Meaningful error messages for invalid inputs and missing data.
- ✅ Tested with Postman – Test cases are documented and executed via Postman.

### 🛠️ **Technologies Used**
- **Java (JAX-RS)** – For developing RESTful APIs.
- **Maven** – For dependency management.
- **Apache** Tomcat – For deployment and server support.
- **JSON** – For request/response formatting.
- **Postman** – For API testing and validation.
